# myopenclaw v0.2.10

补丁版本（2026-11-24）。**主模型源从 DeepSeek 官方切到我们采购的阿里云百炼业务空间**，
模型本身不变（DeepSeek V4.1 Flash，10-17 checkpoint），官方源转为跨厂商兜底；同时把
「哪儿配哪个模型」收进一个注册表，以后换源只改一行。另外本版带上道元的仓库 issue
入口、DNS 解析修复，以及测试环境的全量固定。

## 本版变更

### 模型源：注册表 + 唯一写者（`modelctl`）

过去换一次源要手改 12 个文件（4 个 Hermes profile、Claude Code 的
`settings.json` + cc-connect `config.toml`、虾酱 `openclaw.json`、两个 bot 的 env、
compose 注入），每处写法还不同（裸 id / `provider/model` / `[1M]` 后缀），漏一处
不报错，只是某个 agent 静默跑在旧模型上。

- `config/models.toml`：provider / model / role / binding 的**唯一事实来源**。
  不含密钥与租户端点 —— 密钥只写 `key_env` 变量名，业务空间域名走 `.env` 的
  `ALIYUN_MAAS_BASE_URL`，注册表里只留 `${ALIYUN_MAAS_BASE_URL}/…` 路径形状；
  变量缺失时 `apply` 拒绝执行（不会渲染出半截 URL）。
- `scripts/modelctl.py`：`status`（期望 vs live）、`apply`（幂等渲染，写前备份到
  `~/.cache/modelctl/<ts>/`）、`check`（漂移守卫，exit 1）、`probe`（真打主源与备用源的
  OpenAI + Anthropic 两条链路）。
- 主源 = 百炼业务空间（provider `alibaba-cn`），模型 **`deepseek-v4.1-flash-1017`** ——
  用带日期的 id：百炼把 9 月首版与 10-17 迭代版当两条独立条目上架，未带日期的
  `deepseek-v4.1-flash` 是否滚动没有文档保证。
- 备用源 = DeepSeek 官方 `deepseek-flash`（官方侧它是滚动别名，现在指向 1017）。
  跨**源**兜底，所以 `DEEPSEEK_API_KEY` 不能删。
- TDAI 记忆抽取从 `deepseek-chat` 改为 canonical 的 `deepseek-flash`：旧 id 仍能调通，
  但官方已把它静默路由到 flash（响应里的 `model` 字段就是 `deepseek-flash`），
  依赖别名等于把「哪天路由撤了」当运气。它同时从 `[pinned]` 提升为普通 binding
  （`roles.official`），从此也受 `check` 校验。

### Claude Code：三个静默坑

- **钥匙按名字取**：entrypoint 按 `.env` 的 `CLAUDE_MODEL_KEY_ENV` 间接取
  `ANTHROPIC_API_KEY`，不再硬编码 `DEEPSEEK_*`。否则换源后是「拿 A 家钥匙打 B 家端点」，
  Claude 只会回 401。
- **旧 id 迁移正则收窄**：`shouldSetModel` 的判据从 `^deepseek-v\d` 改成
  `^deepseek-v\d+(-|$)`，否则 `deepseek-v4.1-flash-1017` 会被当成旧 id、每次启动改写成
  `deepseek-flash[1M]` —— 配百炼端点就是 404，且看起来像"配置没生效"。
- **上下文窗口**：Claude Code 不认识非 Anthropic 的模型 id，默认按 200K 算
  （实测 warning）。注册表的 `claude_max_context` 渲染成
  `CLAUDE_CODE_MAX_CONTEXT_TOKENS=983616`，不设不报错、只是长会话提前压缩。
- ⚠️ entrypoint 烘在镜像里：升级时必须 `docker compose build claude-code`，
  只 `up -d` 会继续用旧 entrypoint。

### bot 的能力元数据不再硬编码

知汛 / 天一原来在模板里写死 `contextWindow: 128000` / `maxTokens: 8192`，切到 1M 模型
会被静默截断。现在由 `*_MODEL_CONTEXT_WINDOW` / `*_MODEL_MAX_TOKENS` 在渲染时覆写
（当前 1000000 / 393216），模板保持合法 JSON（数字字段不能走字符串占位符）。

### 道元：仓库 issue 入口（`repo-issue-intake`）

道元可通过 skill 直接给我们自己的仓库建 issue：GitHub `OuyangWenyu/*` /
`iHeadWater/*` 与 GitCode `dlut-water/*` 共 39 仓白名单，建单前查重、凭据扫描、
写后回读校验。gh 走 `GH_CONFIG_DIR=/opt/gh-config`（Hermes 会从 terminal 子进程剥离
`GH_TOKEN`/`GITHUB_TOKEN`），gitcode 用 `GITCODE_TOKEN`。详见
[仓库 issue 入口](../repo-issue-intake.md)。

### DNS：阿里域名解析补齐

- resolver 增加 `aliyun.com` 与 `initaq.com`（`www.aliyun.com` 的 CNAME 终端，
  mDNSResponder 是逐跳按后缀选 resolver 的，只钉第一跳会让终端跳落回默认 DNS）；
- 验证域名增加 `bailian.console.aliyun.com`；
- 修一处 `/etc/hosts` 脏行：旧逻辑 `awk '{print $1}' | head -1` 会把 `-e 43.x` 这类
  写坏的行的 `-e` 当 IP，于是判定「已有条目」、既不更新也不追加，`workbuddy.cn` 的
  兜底条目静默缺失。

### 测试环境全量固定

`pytest.importorskip("pylatexenc")` 让 `test_feishu_latex` 在宿主环境里恒 skip
（每次全量都是 "1 skipped"）。新增 `dev` 依赖组（pytest / pyyaml / pylatexenc），
三处"全量"命令统一成 `uv run --group dev pytest tests/ -q`。

## 升级注意

1. **补两个部署专属值**到仓库根 `.env`（模板见 `.env.example`）：

   ```bash
   ALIYUN_MAAS_BASE_URL=https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com
   DASHSCOPE_API_KEY=sk-...
   ```

2. **先验证再切**：

   ```bash
   python3 scripts/modelctl.py probe      # 主源 + 备用源各三条链路
   python3 scripts/modelctl.py apply      # 缺 key / 端点会拒绝执行
   ```

3. **重建容器**（环境变量变了，`restart` 不重读）：

   ```bash
   docker compose build claude-code       # entrypoint 烘在镜像里，必须先构建
   docker compose up -d hermes hermes-coder hermes-finance hermes-daoyuan \
     claude-code openclaw-gateway tdai-memory
   ./scripts/start-zhixun-bot.sh && ./scripts/start-tianyi-bot.sh
   ```

   虾酱若正在跑启动迁移，等它自行完成再重启（见 CLAUDE.md）。

4. **回滚**是一行：把 `config/models.toml` 的 `[roles.primary].model` 改回
   `deepseek-flash`，再 `modelctl apply` + 重建。Claude Code 会自动拿回 `[1M]` 后缀。

## 已知边界

- **带日期的快照会下线**：`deepseek-v4.1-flash-1017` 是百炼的固定快照，到期需改注册表
  一行并 `apply`；未带日期的 id 语义未文档化，本版不赌它。
- **语音（TTS/STT）仍钉在 DeepSeek 官方**：它走专用接口，不是兼容协议，切不过去。
- **扫码新增的助手暂不参与切换**：它们的 compose 在创建时固化（`env_keys` 已预留
  `DASHSCOPE_API_KEY`），收编需重建容器。
- **两个 bot 的兜底仍是 `zhipu/glm-5.3-flash`**：模板只有一条兜底条目。
- **`.env` 不在 git 里**：换机 / 从快照恢复要重新补上面两个值。
