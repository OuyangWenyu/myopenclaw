# myopenclaw v0.2.7

补丁版本（2026-11-15）。这一版把 **Hermes 的语音输入/输出做成默认能力**：四个固定
profile 和扫码新增的 bind agent 都自带 DeepSeek TTS/STT，不再需要每个 agent
单独改 config。OpenClaw 三个栈没有改动。

## 本版变更

### Hermes 默认语音：DeepSeek TTS/STT

- 新增镜像内运行时 `/opt/hermes-voice/ds_voice.py`：
  - `tts`：调用 `POST /v1/tools/tts`，支持 `stella` / `tide`，默认 wav，可转 mp3；
  - `asr`：调用 `POST /v1/tools/asr`，支持 WAV / Ogg Opus，其他格式用 ffmpeg 转 16k 单声道；
  - 纯 Python 标准库，不依赖 PyYAML / requests；
  - 429/503/504/408 与网络错误重试 3 次；8 MiB / 120 秒 / 10,000 计费字符限制前置检查；
  - 支持 Hermes 的 `--text-file` 与 OpenClaw 后续要用的 `--text` / `--stdout`。
- 新增 `/opt/hermes-voice/voice_config.py`：幂等配置注入器。
  - 只编辑 `tts` / `stt` / `voice` 段，保留注释、键序、缩进、换行风格；
  - 只把 `edge` / `local` / 空切到 `deepseek`，显式选择的其他 provider 原样保留；
  - 迁移旧的 `/opt/data/bin/ds_*.py` 路径与旧 env key；
  - 改动前生成 `config.yaml.bak.voice-<时间戳>`，可 `--dry-run` / `--check`。
- 接入路径：
  - `scripts/start.sh` 用 glob 覆盖 `~/.hermes/config.yaml`、`~/.hermes/profiles/*/config.yaml`、
    `~/.hermes-agents/*/profiles/*/config.yaml`，不写死 profile 名；
  - `scripts/bind_agent.py` 在新建 agent 时直接写入同样的配置，`voice.auto_tts: true`；
  - 所有 Hermes profile 默认 `voice.auto_tts: true`：**你发语音，它回语音**；
    要所有回复（含文字消息）都语音，在会话里发 `/voice tts`；`/voice off` 关闭。
- 文档：[`docs/voice.md`](../voice.md)。

### auto-TTS 被安全写根拒绝：修复“只回文字”

Hermes 的 gateway auto-TTS 固定把音频写到 `/tmp/hermes_voice/`，而基础镜像设置
`HERMES_WRITE_SAFE_ROOT=/opt/data`，TTS 工具把该路径判成“受保护路径”并返回
`success: false`；`_synthesize_auto_tts` 对失败不打日志，表现为**语音消息只回文字**。

- 镜像设置 `HERMES_WRITE_SAFE_ROOT=/opt/data:/tmp/hermes_voice`，只放行 auto-TTS 的临时目录；
- 守卫 `tests/test_voice_wiring.py` 钉住该值；
- 文档记录症状与排查路径。

### dailyinfo 每日三路推送自检（随本版发布）

  并入 `install-all-schedulers.sh`；

## 升级注意

1. **重建 hermes 镜像并重建容器**：
   ```bash
   docker compose build hermes
   docker compose up -d hermes hermes-coder hermes-finance hermes-daoyuan
   ```
   已有 bind agent 也要重建：
   ```bash
   docker compose -f ~/.hermes-agents/compose.yml up -d
   ```
2. **配置会被 `scripts/start.sh` 幂等注入**：默认 profile 与三个 profile 的
   `tts/stt` provider、`voice.auto_tts` 会自动补齐；旧配置会生成
   `config.yaml.bak.voice-<时间戳>`。如果不想让 `start.sh` 每次把
   `voice.auto_tts` 设为 true，可在会话里 `/voice off`（按聊天持久化），
   或手动改回 false 并调整 `scripts/start.sh` 的 `--auto-tts true`。
3. **飞书语音仍是点击播放**：飞书客户端没有“收到语音自动播放”的开关；
   设置里只有“语音消息自动转为文字”。需要免点击时开自动转文字，或换渠道。
4. **成本/隐私**：TTS 1.5 元/万计费字符（限时 5 折，汉字算 2 字符），
   ASR 0.39 元/小时（限时 5 折）；语音和回复文本都会上传 DeepSeek。
   所有 agent 共享同一账号的 50 并发上限。
5. **回滚**：恢复 `~/.hermes/.../config.yaml.bak.voice-<时间戳>`，并回退镜像即可；
   voice 配置不影响文本聊天。

## 已知边界

- **飞书不能自动播放语音**：语音气泡必须点一下；这是客户端行为，机器人无法强制。
- **Hermes 的 auto-TTS 只覆盖“语音输入回合”**：普通文字消息默认仍回文字；
  要所有回复都语音，用 `/voice tts`。
- **Hermes 没有 TTS/STT provider fallback**：DeepSeek 503/429 重试耗尽后，这一条
  语音会失败（文字回复不受影响）；OpenClaw 的 fallback 链不在本版范围。
- **本地 STT 仍未修复**：镜像里的 faster-whisper 因 numpy 冲突不可用，本版默认走
  DeepSeek 云端 ASR；需要离线/免费时再单独修本地 whisper。
- **OpenClaw 三个栈未改动**：虾酱/zhixun/tianyi 的 TTS/STT 仍是原状态。
