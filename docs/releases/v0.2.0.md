# myopenclaw v0.2.0

首个 GitHub Release（2026-11-08）。版本由 uv 管理；本次不上传 PyPI，也不附加 wheel/sdist。

> ⚠️ **本版的 `uv.lock` 未同步**：发布时手工改了 `pyproject.toml`，没有走 `uv version`。检出 `v0.2.0` 后执行 `uv sync --locked` 会提示 lockfile 需要更新。**请优先使用 [v0.2.1](v0.2.1.md)**；`v0.2.0` 保留为历史 tag，不移动。

## 本版提供

- **dailyinfo 独立栈**：FreshRSS + scheduler（supercronic）+ 只读 MCP 收进 dailyinfo 自己的 compose；myopenclaw 删除 `freshrss` 服务与 8 个 `ai.dailyinfo.*` launchd 任务，改为 `start.sh` 软拉起（`DAILYINFO_LOCAL_STACK`）+ MCP 消费（道元 / 虾酱）。
- **服务监控**：server-monitoring MCP 接入爱玛士 / 爱码士 / 天一；Hermes 每日 08:30 服务器日报；server-health-notifier 健康事件通知。
- **issue/PR 通知**：repo-scanner watcher + issue-notifier → 飞书群，含游标、去重、重试、脱敏与 AgentOps 心跳。
- **语雀 MCP 本机化**：yuque-mcp 容器（pin `543f6fe`，11 tools），每日 08:10 变更日报。
- **Claude Code / cc-connect 版本 pin**：四个 npm 工具显式 pin，守卫测试防漂移。
- **飞书渲染**：Markdown 回复卡片化、话题回复锚点修复、公式 → 图片。
- **模型与兜底**：deepseek-flash 主模型；GLM / Kimi 兜底；OpenClaw 2026.9.1 三栈统一。
- **备份与监控**：活 SQLite 热备清单覆盖；Uptime Kuma 注册脚本改为停库 → 写 → 启动。

## 升级注意

- dailyinfo 不再由 myopenclaw compose 托管：先确保 `~/code/dailyinfo` 的 `.env` / secrets 就绪；`DAILYINFO_LOCAL_STACK=0` 可关闭本机拉起。
- 旧 `ai.dailyinfo.*` launchd 任务已删除；不要再用 `install-dailyinfo.sh`。
- `.env` 需配置 `DAILYINFO_MCP_URL` / `DAILYINFO_MCP_KEY`；道元与虾酱由 `start.sh` 自动注册。
- Uptime Kuma 监控项改为 `dailyinfo-freshrss` / `dailyinfo-scheduler`；`FreshRSS` 探针走 `host.docker.internal:8081`。
