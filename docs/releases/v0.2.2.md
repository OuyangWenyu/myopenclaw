# myopenclaw v0.2.2

补丁版本（2026-11-08）：论文清单从虾酱整体交接给道元；道元 Feishu 权限收紧为个人
私聊；dailyinfo 每日全量简报镜像到道元飞书私聊。**不改 dailyinfo 代码**。

## 本版变更

### 论文清单交给道元

- `paper-queue-mcp` 增加 **Bearer token → 固定 actor** 通道：道元请求带
  `Authorization: Bearer ${PAPER_QUEUE_DAOYUAN_TOKEN}`，服务端绑定到
  `PAPER_QUEUE_DAOYUAN_ACTOR_ID`（Owen），忽略客户端传入的 `actor_*` / `actor_sig`
- **同一个服务、同一个库**：`~/.myagentdata/paper-queue/queue.sqlite` 原样继承，
  历史 180 行不迁不删；道元新增行追加
- skill 只有一份：`skills/paper-queue/SKILL.md`（`openclaw/skills/paper-queue/`
  已删除），道元通过 compose 只读挂载 + `start.sh` symlink 使用
- 虾酱侧下架：`start.sh` 不再安装 MCP/插件/skill，并用
  `scripts/remove_openclaw_paper_queue.py` 清理 live 残留（MCP 条目、插件、
  `plugins.allow`、`plugins.load.paths`、skill 副本）
- 旧 OpenClaw HMAC 插件/ensure 脚本与密钥**保留**，作为未来道元多用户身份插件的
  参考实现；`PAPER_QUEUE_ACTOR_SECRET` 默认**不注入** server（路径休眠）

### 道元权限收紧

- `FEISHU_GROUP_POLICY=disabled`：群聊不再响应
- `FEISHU_ALLOWED_USERS=${DAOYUAN_FEISHU_ALLOWED_USERS}`：只允许 Owen 私聊
- 移除 `GATEWAY_ALLOW_ALL_USERS=true`
- ⚠️ `DAOYUAN_FEISHU_ALLOWED_USERS` **必须非空**；留空是 Hermes 的 pairing 模式
  （会回复配对码），不是 deny-all

### dailyinfo 全量简报镜像

- 道元 profile 的 no-agent cron `dailyinfo-digest`：每日 07:30（北京）把当天 5 类
  briefing 正文推到道元飞书私聊，不经过 LLM
- 飞书友好清洗（只影响镜像，不改 dailyinfo 原文）：
  - `   > 摘要` → `**摘要：** 摘要`（飞书卡片不渲染 blockquote）
  - `&lt;i&gt;` / `<em>` / `&lt;sub&gt;` 等 HTML 解码后去标签
  - `<br>` → 换行；`P &lt; 0.05` 等字面量比较保留

## 升级注意

1. `.env` 新增（真实值只放 `.env`）：
   ```env
   DAOYUAN_FEISHU_ALLOWED_USERS=ou_...        # 道元应用维度 open_id，必须非空
   PAPER_QUEUE_MCP_URL=http://paper-queue-mcp:8003/mcp
   PAPER_QUEUE_DAOYUAN_TOKEN=...              # start.sh 缺失时自动生成
   PAPER_QUEUE_DAOYUAN_ACTOR_ID=...           # 缺失时从 DISCORD_ALLOWED_USERS 取并校验
   ```
2. 需要重建 `paper-queue-mcp`（token 通道 + `mcp==1.30.0` pin）：
   ```bash
   docker compose build paper-queue-mcp
   ./scripts/start.sh
   ```
3. `start.sh` 会自动清理虾酱侧的 paper-queue 残留；道元群聊将不再响应（有意）。
4. 旧 HMAC 路径默认休眠；要恢复多用户 HMAC 客户端时，取消 compose 里
   `PAPER_QUEUE_ACTOR_SECRET` 那行注释。

## 已知边界

- `claude-code` 仍以 RW 挂载整个 `~/.myagentdata`（并能读到仓库 `.env`），
  `hermes`/`hermes-coder` 以 RO 挂载 `~/.myagentdata`；因此“队列文件对所有 agent
  不可达”目前不成立。这是本版之前就存在的隔离缺口，已在 `docs/paper-queue.md`
  如实记录，收窄挂载留作后续独立任务。
- 道元容器内可读取 `PAPER_QUEUE_DAOYUAN_TOKEN`，但 token 只能写 Owen，无法伪造成
  其他 actor。
- 道元群聊禁用后，文献平台群不再响应道元——这是本版的预期行为。
