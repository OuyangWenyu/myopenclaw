# myopenclaw v0.2.1

补丁版本（2026-11-08），修正 `v0.2.0` 的 `uv.lock` 未与项目版本同步的问题。**无业务代码/配置变更**。

## 修正

- 用 `uv version --bump patch` 将 `pyproject.toml` 与 `uv.lock` 同步到 `0.2.1`（`v0.2.0` 的 lockfile 仍是 `0.1.0`，`uv sync --locked` 会失败）
- 新增 `.github/workflows/release-checks.yml`：`uv sync --locked`、项目版本 / tag 一致性、pytest、`mkdocs build --strict`
- 新增 [发布流程](../releasing.md) 与 `docs/releases/` 版本说明目录

## 使用

```bash
git clone --branch v0.2.1 https://github.com/OuyangWenyu/myopenclaw.git
cd myopenclaw
uv sync --locked
./scripts/start.sh
```

## 验收

- `uv lock --check`：通过
- `uv sync --locked`：通过
- `pytest tests/`：917 passed
- `mkdocs build --strict`：通过

## 说明

`v0.2.0` 已公开，按发布约定不删除/移动 tag；如需使用请以 `v0.2.1` 为准。后续版本一律先用 `uv version` 更新版本与锁文件，再打 tag。
