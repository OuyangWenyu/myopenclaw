# 语雀每日变更日报

本 skill 由 Hermes cron 每日早间触发（北京时间 08:10，服务端每天 07:00 已生成最新变更报告），也可由用户手动触发。必须在全新 session 中自包含执行，不依赖任何外部脚本、文件或历史上下文。只使用已配置的 `yuque-mcp` 提供的工具。

## 执行流程

1. **解析知识库列表**：cron prompt 会给出要跟踪的知识库显示名列表（如「知识库A,知识库B」）。先调用 `list_repos` 获取各显示名对应的 `namespace`；禁止凭名称猜测 `namespace`。若某显示名找不到或存在多个同名候选，不要自行选择，按错误处理输出警告并列出候选。
2. **逐一获取变更报告**：对每个知识库分别调用 `get_change_summary`（不要把多个知识库合并成一次调用）。该工具只读服务端最新生成的变化报告，不会创建快照、不会读取语雀正文、不会推进基线。
3. **摘要重点变更**：仅当某知识库存在实质文档变更时，对其中最重要的变更文档调用 `get_doc_content` 读取正文（单库不超过 3 篇，总量不超过 5 篇），只摘取与变更相关的增量信息，不大段复述全文。若变更仅为删除或元数据变动，无需读取正文。
4. **生成日报**：把日报全文作为最终回复输出。cron 会自动把最终回复推送到飞书私聊，不要调用任何发送消息工具，不要使用 send_message。

## 输出格式

- 纯文本 + emoji + `━━━` 分隔线，禁止出现 `###` 等 Markdown 标题（`#`/`##`/`###`），飞书私聊按纯文本渲染。
- 参考结构：

```
━━━ 语雀变更日报 ━━━

📚 知识库：<显示名>

📄 变更清单
  🆕 新增：<文档标题>（可多行）
  ✏️ 修改：<文档标题>
  🗑 删除：<文档标题>

📝 重点变更摘要
  • <文档标题>：<2-4 句中文摘要>

ℹ️ 数据口径：本报告是服务端固定快照之间的净变化，不是自然日日报、完整版本历史或官方审计记录。
```

- 某节无内容时省略该节；多个知识库时逐库重复「变更清单 + 摘要」小节。

## [SILENT] 协议

- `[SILENT]` **仅限**所有跟踪知识库的变更报告都是干净的「无变更」。其余任何非正常情况一律输出警告，不得静默。
- 出现下列任一情况时**必须输出简短警告**，不许静默（管道断了自己要知道）：
  - `get_change_summary` 返回 `initialized` → 「⚠️ 语雀变更基线已建立，明日起推送日报」
  - `get_change_summary` 返回 `not_available` → 「⚠️ 语雀服务端尚未完成调度生成，今日无变更报告」
  - 服务返回 401 或连接失败 → 「⚠️ yuque-mcp 认证或连接失败，语雀日报中断」
  - 某知识库返回「未纳入监控/未监控」→ 「⚠️ 知识库「<名称>」未纳入服务端变更监控，请检查服务端配置」
  - 返回内容为无法识别的状态或异常 → 如实转述，视为故障警告，不得当作「无变更」
  - 某知识库显示名无法解析 → 「⚠️ 未找到知识库「<名称>」，可用：<候选列表>」
  - 知识库列表为空 → 输出警告并说明 cron 配置为空
- 部分知识库成功、部分失败 → 输出成功部分的日报 + 失败部分的警告，不得静默丢弃失败项。

## 错误处理

- 认证、权限或上游错误必须如实报告，不得伪装为空结果。
- 缺少 `MCP_API_KEY`、服务返回 401 或连接失败时，只说明 `yuque-mcp` 认证或连接失败；不要要求用户提供 `YUQUE_TOKEN`（客户端不需要它）。
- 工具不可用时说明 `yuque-mcp` 连接失败，不切换到其他地址、VPN、浏览器凭据或非公开接口。
- 正文、Key、认证头等敏感内容不得写入日志。
